الحد الممتاز ستور — ELHAD ELMOMTAZ STORE
========================================
تشغيل الموقع:
1. ارفع محتويات المجلد كله على GitHub Pages (أو أي استضافة ثابتة).
2. index.html  => واجهة المتجر
3. admin.html  => لوحة التحكم (كلمة السر الافتراضية: alhady2026 — غيّرها من تبويب الإعدادات)

ربط Firebase جاهز (المشروع: alhady). قاعدة البيانات Realtime Database لازم تكون مفعّلة.

هيكل قاعدة البيانات (بيتعمل تلقائياً):
- settings: الأسعار وبيانات الدفع وكلمة السر
- covers: أغلفة المواد (بتتزرع تلقائياً أول مرة تفتح اللوحة)
- orders: طلبات الكشاكيل + الصور + التصميم + بيانات الشحن
- products: منتجات إضافية
